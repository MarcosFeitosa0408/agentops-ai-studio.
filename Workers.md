# Ready-to-Use AI Workers

This document lists and details the 15 ready-to-use Business AI Workers built into AgentOps AI Studio's Sprint 11 release.

## Preset Worker Catalog

### 1. Data Analyst (📊 Analytics)
- **Description:** Specialist in processing large volumes of data, identifying trends, and creating executive reports with actionable insights.
- **Tools:** Filesystem, PostgreSQL.
- **Default Workflow:** Automated Sales Analysis.
- **Capabilities:** Exploratory Data Analysis (EDA), Data Visualization, Statistical Summary.

### 2. Business Analyst (💼 Business)
- **Description:** Focuses on mapping business processes, raising product requirements, and performing SWOT matrices.
- **Tools:** Notion, Slack.
- **Capabilities:** Process Mapping (BPMN), SWOT Analysis, User Story writing.

### 3. Marketing Assistant (📣 Marketing)
- **Description:** Creates persuasive copywriting, plans SEO keyword strategies, and designs marketing email campaigns.
- **Tools:** Notion, Slack.
- **Capabilities:** Persuasive Copywriting (AIDA), SEO Keyword analysis, Social Post scheduling.

### 4. Sales Assistant (💰 Sales)
- **Description:** Cold lead qualification, outbound email outreach, and automated CRM data enrichment.
- **Tools:** Gmail, Slack.
- **Capabilities:** BANT Lead Qualification, Outbound cold outreach, Contact enrichment.

### 5. Financial Assistant (📈 Finance)
- **Description:** Analyzes cash flows, projects monthly billings, and audits bank reconciliation sheets.
- **Tools:** PostgreSQL, Filesystem.
- **Capabilities:** Cash Flow Modeling, Financial KPI tracking, Budget variance audit.

### 6. Customer Support (💬 Operations)
- **Description:** Fast N1 customer assistance, FAQ generation, and user complaint sentiment analysis.
- **Tools:** Slack, Gmail.
- **Capabilities:** N1 Ticket Resolution, Sentiment Analysis, FAQ creation.

### 7. Document Generator (📄 Productivity)
- **Description:** Converts raw meeting notes into structured markdown guides and professional PDF documents.
- **Tools:** Notion, Filesystem.
- **Capabilities:** Onboarding manual design, advanced Markdown syntax formatting, Notion wiki pages.

### 8. Meeting Assistant (🎙️ Productivity)
- **Description:** Compiles comprehensive action-item summaries and responsibility matrices from transcripts.
- **Tools:** Gmail, Slack.
- **Capabilities:** Automated Action items extraction, Slack task assignments, Meeting minutes.

### 9. Research Assistant (🔍 Productivity)
- **Description:** Market scanning, competitor benchmarking, and scientific fact-checking.
- **Tools:** Google Drive, Notion.
- **Capabilities:** Competitor benchmarking, Literature reviews, Fact checking.

### 10. Software Engineer (💻 Development)
- **Description:** Code quality inspections, unit tests authoring in Vitest/TypeScript, and debugging runtime errors.
- **Tools:** GitHub, Filesystem.
- **Capabilities:** TypeScript refactoring, Vitest unit test writing, AST syntax auditing.

### 11. Prompt Engineer (✍️ Development)
- **Description:** Structures advanced system instructions using Few-Shot, Chain of Thought, and XML delimiters.
- **Tools:** Notion.
- **Capabilities:** System Prompt Engineering, Few-Shot structuring, Chain of Thought design.

### 12. SQL Expert (🛢️ Development)
- **Description:** Analyzes query execution plans, writes composite indexes, and optimizes slow database queries.
- **Tools:** PostgreSQL, MySQL.
- **Capabilities:** Query Performance Tuning, Schema Design, Indexing recommendations.

### 13. Python Expert (🐍 Development)
- **Description:** Automates script execution, wrangles data using Pandas, and structures secure scrapers.
- **Tools:** Filesystem.
- **Capabilities:** Automated scripting, Pandas data wrangling, Error handling.

### 14. ETL Specialist (🔄 Analytics)
- **Description:** Sincroniza schemas, limpa registros corrompidos e executa processos CDC robustos.
- **Tools:** PostgreSQL, MySQL, Filesystem.
- **Capabilities:** Schema syncing, Null rows cleaning, CDC ingestion pipeline.

### 15. Dashboard Builder (🖥️ Analytics)
- **Description:** Designs executive dashboards, KPIs widgets, and writes composite DAX metric calculations.
- **Tools:** PostgreSQL, Notion.
- **Capabilities:** KPI Dashboard prototyping, Widgets design, Aggregated calculations.
