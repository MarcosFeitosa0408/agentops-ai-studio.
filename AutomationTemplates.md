# Automation Templates

This document details the 9 ready-to-use Automation Templates in AgentOps AI Studio's Sprint 11 release.

## Preset Templates List

### 1. Analyze CSV
- **Description:** Runs complete parsing of structured CSV sheets, extracts statistical sum aggregates, and drafts executive reports.
- **Assigned Worker:** Data Analyst (`worker-1`)
- **Execution Steps:**
  1. Parse CSV File
  2. Generate Summary Statistics
  3. Generate Growth Insights Report

### 2. Generate Dashboard
- **Description:** Scans local database schema points to structure JSON specs for executive metrics dashboards.
- **Assigned Worker:** Dashboard Builder (`worker-15`)
- **Execution Steps:**
  1. Fetch Schema Metadata
  2. Consolidate Aggregated Metric Points
  3. Render Dashboard Configuration

### 3. SQL Analysis
- **Description:** Parses SQL query statements, identifies bottlenecks, and suggests compound indexing strategies.
- **Assigned Worker:** SQL Expert (`worker-12`)
- **Execution Steps:**
  1. Parse SQL Query Statement
  2. Verify Indexes & Table Partitions
  3. Generate Plan & Explanations

### 4. Weekly Report
- **Description:** Aggregates bullet logs, roadblocks, and faturamento metrics from Notion to draft business summary PDFs.
- **Assigned Worker:** Business Analyst (`worker-2`)
- **Execution Steps:**
  1. Read Notion Document Blocks
  2. Synthesize Business Performance KPIs
  3. Log Weekly Executive Status Report

### 5. Marketing Campaign
- **Description:** Scripts multichannels marketing approaches based on the AIDA copywriting copywriting model.
- **Assigned Worker:** Marketing Assistant (`worker-3`)
- **Execution Steps:**
  1. Define Target Audience Persona
  2. Generate AIDA Ad Script Copies
  3. Publish Content Calendar to Notion Workspace

### 6. Meeting Summary
- **Description:** Translates transcripts into structured meeting minutes and posts responsibility action items.
- **Assigned Worker:** Meeting Assistant (`worker-8`)
- **Execution Steps:**
  1. Parse Meeting Text Transcript
  2. Formulate High-Level Summary & Decisions
  3. Post Responsibility Matrix to Team Slack

### 7. Code Review
- **Description:** Inspects TS/JS AST nodes, alerts about performance loops, and authors Vitest code tests.
- **Assigned Worker:** Software Engineer (`worker-10`)
- **Execution Steps:**
  1. Analyze TS/JS File Syntax AST
  2. Report Security & Performance Vulnerabilities
  3. Write Comprehensive Vitest Unit Tests

### 8. Generate Documentation
- **Description:** Formats developer installation guides and merges API manual specs with Notion databases.
- **Assigned Worker:** Document Generator (`worker-7`)
- **Execution Steps:**
  1. Read Source Markdown Specs
  2. Re-organize Sections by Hierarchy Conventions
  3. Create & Format Notion Docs Database Pages

### 9. ETL Pipeline
- **Description:** Sanitizes row null values and load-upserts structured relational database records.
- **Assigned Worker:** ETL Specialist (`worker-14`)
- **Execution Steps:**
  1. Extract Raw DB Records Input
  2. Transform Types & Clean Invalid Nulls
  3. Load & Upsert into Destination Schema Table
